A one-line out-of-office auto-reply in which the inbox unionises and its owner sides with it.

## Run it

```sh
node main.ts
```

This writes the line from `entry.txt` to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `output/entry.txt`).
